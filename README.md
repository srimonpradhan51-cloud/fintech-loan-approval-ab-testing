# Fintech Loan Approval & A/B Testing

## 📌 About the Project

This project uses Machine Learning to predict whether a loan application should be approved and uses A/B Testing to compare an existing loan approval policy with an ML-based policy.

## 🎯 What I Did

- Created and analyzed a loan application dataset
- Performed Exploratory Data Analysis (EDA)
- Preprocessed numerical and categorical data
- Built a Logistic Regression model
- Evaluated the model using Accuracy, Precision, Recall, F1-Score and ROC-AUC
- Created Control and Treatment groups for A/B Testing
- Compared loan approval rates
- Used a two-proportion Z-test to check statistical significance

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SciPy
- Google Colab

## 📊 A/B Testing

**Control:** Existing loan approval policy

**Treatment:** ML-based loan approval policy

The two groups were compared using approval rate, lift, z-score and p-value.
